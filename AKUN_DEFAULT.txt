CARA JALANKAN APLIKASI
----------------------
1. Buka Terminal/Command Prompt
2. Jalankan:
   cd "C:\laragon\www\Aplikasi MOZU\mozu"
   php artisan serve
3. Buka browser: http://localhost:8000


CATATAN PENTING
---------------
- Pastikan Laragon sudah running
- Pastikan database db_mozu sudah dibuat
- Untuk reset data, jalankan:
  php artisan migrate:fresh --seed


STRUKTUR APLIKASI
-----------------
Customer Area:
- / (Home - Browse Produk)
- /cart (Keranjang)
- /order/checkout (Checkout)
- /order/my-orders (Pesanan Saya - Auth Required)
- /login (Login)
- /register (Register)

Admin Area:
- /admin/dashboard (Dashboard)
- /admin/products (Kelola Produk)
- /admin/orders (Kelola Pesanan)
- /admin/reports (Laporan)
